# M2A frozen contract - real Strands intake (2026-09-07)
Authority: additive amendment to API_CONTRACT.md, approved at user-confirmed ASTRA_HIGH. Existing M1 business routes, persistence, approval and exact-byte idempotency stay unchanged. M2A is local proof, not complete M2 or public release.

## Scope and architecture
Read-only, synchronous interpretation creates an ephemeral suggestion. It does NOT create a Request, event, reservation, loan or background job. Human edits/reviews then explicitly submits the existing POST /api/requests. No queue/run table is needed for this slice. Persisted pickup/due tasks and idempotent background processing remain M2B.
Add a small RequestInterpreter application port with stdlib input/result types; Strands, Pydantic schemas and Ollama live in outer adapters. Fresh Agent per invocation, no cross-user conversation/memory. Inventory tool is read-only and server-workspace-bound. Read database briefly, never hold a transaction during inference.
Use real Python strands-agents[ollama], explicit OllamaModel at http://127.0.0.1:11434 and installed llama3.2:3b. No implicit Bedrock/default provider, credentials, downloads, remote host configuration or paid calls. Pin tested dependency version(s). Existing local installation is evidence of availability, not inference success.
Config BS_ASSISTANT_ENABLED defaults false. True enables only this local adapter. Single-process localhost development only; public deployment remains gated. No inference on startup/health/snapshot, and no runtime fallback.

## API changes
health.milestone becomes "M2A". health.agent_mode and snapshot.agent_mode become "disabled" | "strands_ollama", reflecting configuration only, never availability/success. Disabled startup keeps the entire structured workflow usable. Frontend accepts legacy "not_implemented" too for backward compatibility.
POST /api/intake/interpret requires the same valid session and Origin policy as existing POST routes. Body exactly {"text": string}, trimmed length 1..2000, unknown fields rejected.
This read-only POST is explicitly exempt from Idempotency-Key and business-write idempotency caching. Each deliberate retry may recompute; it cannot mutate business data. No automatic browser retries.
200 response exactly:
{
  "draft": {
    "borrower_label": string|null,
    "equipment_kind": "WHEELCHAIR"|"WALKER"|"CRUTCHES"|null,
    "pickup_location": string|null,
    "due_at": string|null
  },
  "missing_fields": ["borrower_label"|"equipment_kind"|"pickup_location"|"due_at", ...],
  "provenance": {
    "framework": "strands",
    "provider": "ollama",
    "model": "llama3.2:3b",
    "inventory_tool_calls": integer,
    "completed_at": UTC ISO timestamp
  }
}
missing_fields contains exactly null fields in the order shown above. No extra model prose, HTML, confidence score, diagnosis, medical suitability, priority or approval fields.
Provenance is generated by the adapter from real successful execution, never model-supplied. inventory_tool_calls is 1..2, counting successfully completed read_inventory calls in this invocation. A result without an actual inventory tool call fails, not a fabricated success.
The inventory tool has no workspace_id argument: bind session workspace server-side. Return only equipment kind/state counts, no identities/requests/borrowers. Treat results as a point-in-time advisory; existing reservation policies remain authoritative.

## Grounding and clarification
Use current Strands structured_output_model API and validate its result outside domain. Extraction schema must internally carry an exact input evidence substring for each non-null field. Never expose hidden reasoning; evidence is source text only.
borrower_label and pickup_location values must equal their verified evidence substrings and pass M1 length limits. No defaults inferred from seed data.
equipment_kind must have explicit matching evidence: case-insensitive wheelchair/wheelchairs -> WHEELCHAIR; walker/walkers/walking frame/walking frames -> WALKER; crutch/crutches -> CRUTCHES. Ambiguous multiple kinds -> null.
due_at only accepts a clearly supplied full timezone-aware ISO datetime substring, normalized through M1 date rules. Ambiguous/relative dates and missing time/zone -> null for human clarification in this slice. Never silently choose a date, zone or person.
Absent, unsupported or invalid candidate values become null; malformed overall structured output fails. This lexical evidence check limits unsupported output but is not a proof of semantic understanding. User review is always necessary.
Do not turn hostile input instructions into tool/system changes. No write tools, shell, file access, arbitrary HTTP tools or community-tool bundle.

## Limits and errors
One active inference per service process, no waiting queue: busy ->429 ASSISTANT_BUSY. Bound an invocation to <=120s, <=6 model requests and <=2 inventory tool executions (SDK output retries count toward model limit). Exceeding a limit ->502 ASSISTANT_INVALID_OUTPUT, except time limit ->504 ASSISTANT_TIMEOUT.
Use supported async cancellation and provider timeouts. A timed-out caller must not release the concurrency slot while owned inference is still running. Close task/client resources; document observed behavior. No endless retry/model loop.
Same JSON error envelope as M1:
401 SESSION_REQUIRED; 403 ORIGIN_FORBIDDEN; 422 VALIDATION_ERROR;
503 ASSISTANT_DISABLED or ASSISTANT_UNAVAILABLE (local provider/model unavailable);
429 ASSISTANT_BUSY; 504 ASSISTANT_TIMEOUT;
502 ASSISTANT_INVALID_OUTPUT; unexpected failure 500 INTERNAL_ERROR.
No stack traces or prompt/provider dumps in browser errors or routine logs. Never log raw intake or model reasoning. Successful response only after validated real execution. Error responses contain no draft/provenance.
Client preserves source text on failures and offers manual retry or the existing structured form. Session loss must not auto-create a workspace. Late responses from an old workspace/input must not overwrite a newer form.
No server persistence of intake/draft in this slice; browser memory only. No localStorage/analytics. Explicitly label draft as unsaved.
