## 1. Objective & Scope

Implement the human-reviewed synthetic intake suggestion UI against the frozen M2A contract (`docs/M2A_CONTRACT.md`), independently of Claude's backend implementation.

Key capabilities delivered:
1. **Bounded Synthetic Intake UI**: A controlled textarea (1–2000 characters) with explicit guidance on ISO datetime requirements, limitation of relative dates (e.g. 'next week'), and synthetic test data constraints.
2. **Advisory Read-Only Interpretation**: Calls `POST /api/intake/interpret` without `Idempotency-Key` (exempt from domain mutation).
3. **Unsaved Ephemeral Draft Review**: Renders extracted fields, clear 'Clarification needed' notices for missing/null fields, and validated call provenance (`framework`, `provider`, `model`, `inventory_tool_calls`, `completed_at`).
4. **Deliberate Human-in-the-Loop Application**: Populates the request form only on deliberate click of 'Use Draft (Populate Form)'. Explicit submission remains separate via 'Register Structured Request' (`POST /api/requests`). Never automatically creates, reserves, or approves requests.
5. **Exact Instant-Preserving Datetime Utilities**: `isoToLocalInput` and `localInputToIso` in `apps/web/src/utils/dateTime.ts` ensure exact epoch millisecond instant preservation between UTC ISO strings and HTML `<input type="datetime-local">` controls.
6. **Agent Mode Display & Provenance**: Agent mode is displayed as configuration metadata (`disabled`, `strands_ollama`, `not_implemented`), never claiming provider health on load. Provenance is displayed exclusively after validated success.
7. **Honest Error Handling & Input Preservation**: Transparent handling for 401, 403, 422, 429 (`ASSISTANT_BUSY`), 502 (`ASSISTANT_INVALID_OUTPUT`), 503 (`ASSISTANT_UNAVAILABLE` / `ASSISTANT_DISABLED`), 504 (`ASSISTANT_TIMEOUT`), 500, and offline connection errors. Input text is preserved; deliberate retry and manual entry are provided in active flow with `role="alert"`. No automatic retries or destructive workspace resets.
8. **Stale Response Protection & Mutex Guards**: Monotonic request ID counter, `AbortController`, and active workspace ID tracking prevent late or stale network responses from overwriting newer user inputs or manual edits. Synchronous mutex locks prevent duplicate submission clicks.
9. **Accessibility & Responsive Layout**: Accessible ARIA roles (`status`, `alert`, live regions), keyboard navigation, zero horizontal overflow on desktop (1280px) and mobile (390px). Plain text rendering only (no raw HTML injection, no localStorage/logging of intake text).
