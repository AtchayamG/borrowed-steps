## 3. IMPLEMENTATION & RESOLUTION OF FOUR REQUIRED INVARIANTS

### Invariant 1: Uncertainty is preserved until resolved
- **Implementation**:
  - `apps/web/src/api/client.ts`: Wrapped `response.json()` for HTTP 2xx responses in a `try...catch` block. Unreadable or interrupted JSON bodies now throw `ApiClientError(response.status, "RESPONSE_PARSE_ERROR", message)`.
  - `apps/web/src/App.tsx`:
    - Handled `RESPONSE_PARSE_ERROR` and status `0` (`CONNECTION_ERROR`) by preserving the exact route, body, and idempotency key in `uncertainRetry`.
    - Removed the unsafe `handleDismissUncertainRetry` / "Dismiss Retry" button. Unresolved operations cannot be discarded to unlock fresh duplicate submissions.
    - Added single-operation guard: while `uncertainRetry` is pending, subsequent actions are blocked with a clear user notice.
    - Settle uncertainty on definite terminal replay responses: if a replay receives HTTP 200, 400, 401, 403, 404, 409, or 422, `uncertainRetry` is cleared (`setUncertainRetry(null)`), settling the operation rather than trapping the user.
    - Separated confirmed mutation success from snapshot refresh failure: confirmed mutations trigger success cleanup and offer a read-only `Sync Snapshot` retry without re-posting mutations.
- **Verification**: `src/test/CodexR1Regression.test.tsx` [Tests 1 & 2] PASS; `src/test/CorrectionScenarios.test.tsx` [Tests 2 & 3] PASS.

### Invariant 2: Every dialog derives current entity state from latest snapshot
- **Implementation**:
  - `apps/web/src/App.tsx`: Refactored modal states to store only selected entity IDs (`allocatingRequestId`, `inspectingEquipmentId`). Current `allocatingRequest` and `inspectingEquipment` instances are derived dynamically from `snapshot.requests` and `snapshot.equipment`.
  - `apps/web/src/components/AllocationModal.tsx`:
    - Selected item is resolved strictly within `matchingItems` (`availableEquipment.filter(e => e.kind === request.equipment_kind && e.state === "AVAILABLE")`), preventing unavailable items from remaining selected.
    - Added version tracking: if the selected item's version changes or the item becomes unavailable after a 409 snapshot refresh, `humanApproved` is immediately reset to `false` and an explanation notice is displayed.
  - `apps/web/src/components/InspectionModal.tsx`:
    - Tracked `item.version` via `prevVersionRef`. When a 409 conflict refreshes the snapshot, the modal receives the updated `v2` entity, automatically clears `humanApproved`, and preserves the selected `outcome`.
    - Corrected inspection eligibility per API contract: allowed from `AWAITING_INSPECTION`, `REPAIR`, and `QUARANTINED`.
  - `apps/web/src/components/LoanList.tsx`:
    - Refactored `activeAction` to store `loanId` and derive current `activeLoan` and `activeEquipment` from snapshot props.
    - Tracked `activeEquipment.version` and cleared `humanApproved` on version mismatch. Validated state eligibility for `PICKUP` and `RETURN`.
- **Verification**: `src/test/CodexR1Regression.test.tsx` [Test 3] PASS; `src/test/CodexRegression.test.tsx` [Tests 2 & 3] PASS.

### Invariant 3: Recovery is usable inside modal workflows
- **Implementation**:
  - `apps/web/src/hooks/useModalFocusTrap.ts`: Created a shared accessible focus trap hook managing initial focus, `Tab` / `Shift+Tab` boundary wrapping, `Escape` key dismiss, and focus restoration to the triggering button upon close. Replaced 3 duplicate focus implementations.
  - Injected `conflictMessage`, `uncertainRetry`, `onRetryUncertain`, and `isRetryingUncertain` directly into `AllocationModal`, `InspectionModal`, and `LoanList`. Error and retry controls now render directly inside `.modal-content` within the active focus trap and above the backdrop.
  - Settle dialogs upon retry success: `executeMutation` accepts an `onSuccessCleanup` callback passed into the retry closure. When a retry succeeds, `onSuccessCleanup` is called, cleanly closing and settling the modal dialog.
- **Verification**: `npm test` PASS; `npm run test:browser` PASS (verified focus traps, Tab wrapping, Escape dismiss, and focus restoration).
