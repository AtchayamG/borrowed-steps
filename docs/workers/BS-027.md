## 2. Implementation Details

### A. Shared Strands Infrastructure (`strands_common.py`)
- Created `services/agent/src/borrowed_steps/infrastructure/strands_common.py`.
- Consolidates shared prompt templates (`AGENT_SYSTEM_PROMPT`, `AGENT_USER_PROMPT`, `RECOVERY_PROMPT`, `EXTRACTION_SYSTEM_PROMPT`, `EXTRACTION_SCHEMA_HEADING`, `EXTRACTION_USER_PROMPT`, `EXTRACTION_SYSTEM_PROMPT_WITH_SCHEMA`), schema definition `_Extraction` (matching legacy `_Extraction.model_json_schema()`), `ToolBudget`, `build_inventory_tool`, `LIMIT_STOP_REASONS`, `Telemetry`, `emit_telemetry`, and `ground_extraction`.
- **Zero Ollama or provider imports**: completely decoupled from local vs hosted execution.
- Refactored `strands_interpreter.py` to import from `strands_common.py`, preserving exact backwards-compatible aliases for all existing tests.

### B. Hosted Groq Interpreter (`strands_groq_interpreter.py`)
- Implemented `StrandsGroqInterpreter` in `services/agent/src/borrowed_steps/infrastructure/strands_groq_interpreter.py`.
- **Protocols**:
  - `RequestInterpreter`: `async def interpret(text, inventory, cancel, ...)`
  - `CleanupOwner`: `cleanup_unresolved: bool`, `async def resolve_cleanup() -> bool`
- **Admission Sequence**:
  1. Validates input identity (`workspace_id` must be valid UUID4).
  2. Calls `admission_store.reserve(reservation_req)` reserving fixed 6 sends.
  3. Calls `admission_store.mark_dispatched(reservation_id, owner_id)`.
  4. Only after successful dispatch: instantiates `GroqModel` (with pinned model `openai/gpt-oss-20b`, pinned URL `https://api.groq.com/openai/v1`, 110s deadline, 60s timeout).
  5. Executes two-stage Strands flow: stage 1 runs Agent with read-only inventory tool; stage 2 runs structured extraction with source text alone.
  6. In `finally:` block:
     - Closes `GroqModel` via `_close(model)` with bounded timeout.
     - Settles admission record via `admission_store.finish(...)`.
     - Confirmed terminal states (`SUCCEEDED`, `FAILED_CONFIRMED`) strictly require `cleanup_completed=True`.
     - Cancellation (`cancel.is_set()` or `asyncio.CancelledError`) or unclosed client forces state to `UNCERTAIN`, retaining concurrency slot.

### C. Inventory Reader Workspace Exposure (`inventory.py`)
- Added `@property def workspace_id(self) -> str: return self._workspace_id` to `StoreInventoryReader` so admission reservation can extract the workspace identity directly from the inventory reader.

### D. Settings & Application Seam (`config.py` & `app.py`)
- Added `groq_api_key: str | None = field(default=None, repr=False)` to `Settings` in `config.py`, populated from `BS_GROQ_API_KEY`.
