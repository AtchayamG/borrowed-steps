## 2. Implementation Details

### A. Backend Configuration (`services/agent/src/borrowed_steps/config.py`)
- Updated `validate_settings`:
  - Hosted mode with `assistant_enabled=True` is now permitted when `groq_api_key` is provided.
  - Raises `ValueError("Hosted runtime requires an explicit groq_api_key when assistant is enabled.")` if key is missing or empty.

  - Correctly verifies that `BS_GROQ_API_KEY` is provided when `BS_RUNTIME=hosted` and `BS_ASSISTANT_ENABLED=1`.
- Clean with Ruff and strict mypy.

### B. Backend Application Seam (`services/agent/src/borrowed_steps/interfaces/http/app.py`)
- Exported constant `AGENT_MODE_STRANDS_GROQ = "strands_groq"`.
- In `create_app`, sets `agent_mode = (AGENT_MODE_STRANDS_GROQ if resolved.assistant_enabled else AGENT_MODE_DISABLED)`.
- Reused existing `_real_hosted_interpreter` factory function to instantiate `StrandsGroqInterpreter` when `resolved.assistant_enabled` is True in hosted mode.
- In `POST /api/intake/interpret`:
  - When disabled (`assistant is None`), returns 503 `ASSISTANT_DISABLED`.
  - When enabled, invokes `assistant.interpret(...)`, propagating structured responses and mapping domain errors to HTTP statuses:
    - `AssistantBusyError` / 429 -> 429 `ASSISTANT_BUSY`
    - `AssistantTimeoutError` / timeout -> 504 `ASSISTANT_TIMEOUT`
    - `AssistantUnavailableError` / provider failure -> 503 `ASSISTANT_UNAVAILABLE`
    - `AssistantInvalidOutputError` / parse failure -> 502 `ASSISTANT_INVALID_OUTPUT`
    - Stale session / sequence conflicts -> 409 `STATE_CONFLICT`
