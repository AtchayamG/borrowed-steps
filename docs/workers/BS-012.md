## 1. Objective & Implemented Changes

Implemented and verified the small Groq transport adapter (`GroqModel`) subclassing Strands `OpenAIModel` for future M3 hosted deployment, using real SDK serialization and test-only intercepted HTTP transports. Proved tool execution loop, strict schema serialization, sticky 6-send budget, 110s monotonic operation deadline, 60s per-request timeout, cancellation, clean resource closing, and HTTP 429 Retry-After preservation. Zero live model calls (local Ollama or remote Groq); zero cloud provisioning or spend.

### Implemented:
1. **Pinned Dependency Overlay** (`services/agent/requirements-groq.lock`):
   - Pinned 6 extra packages from official PyPI compatible with `strands-agents[openai]==1.54.0` on top of unchanged `requirements.lock`:
     `aws-bedrock-token-generator==1.1.0`, `distro==1.9.0`, `jiter==0.16.0`, `openai==2.54.0`, `sniffio==1.3.1`, `tqdm==4.70.0`.
   - Verified via `uv pip check` (69 compatible packages).
2. **Groq Transport Adapter** (`services/agent/src/borrowed_steps/infrastructure/groq_model.py`):
   - `GroqModel(OpenAIModel)`:
     - Requires explicit `api_key: str`. No environment variable lookups.
     - Pinned endpoint: `https://api.groq.com/openai/v1` (`GROQ_BASE_URL`).
     - Pinned model: `openai/gpt-oss-20b` (`GROQ_MODEL_ID`).
     - Pinned default limits: `DEFAULT_MAX_SENDS = 6`, `DEFAULT_OPERATION_DEADLINE_SECONDS = 110.0`, `DEFAULT_REQUEST_TIMEOUT_SECONDS = 60.0`.
     - Strictly enforces injectable limit reductions only (values exceeding ceilings raise `ValueError`).
     - No network calls or background tasks during import or instantiation.
     - Small `_get_client` seam managing `openai.AsyncOpenAI` instances bound to `_BoundedGroqTransport`.
     - Supports `aclose()` and async context manager (`async with GroqModel(...) as model:`).
   - `_BoundedGroqTransport(httpx.AsyncBaseTransport)`:
     - Target validation: strictly checks scheme `https`, host `api.groq.com`, path `/openai/v1/chat/completions`. Fails closed with `GroqTargetRefusedError` on any mismatch.
     - Sticky budget enforcement: charges `SendBudget` immediately before physical wire dispatch. Rejects 7th send and post-exhaustion calls with `GroqSendBudgetExceededError`.
     - Monotonic deadline: pre-send check, dispatch timeout bound `min(request_timeout, deadline - now)`, and response chunk iteration bound via `_DeadlineByteStream`. Stalls raise `GroqDeadlineExpiredError`.
     - Rate limit handling: captures HTTP 429 status code and parses `Retry-After` header into `last_retry_after: float | None` without sleeping or auto-retrying.
   - Typed error hierarchy: `GroqModelError`, `GroqSendBudgetExceededError`, `GroqDeadlineExpiredError`, `GroqRequestTimeoutError`, `GroqTargetRefusedError`, `GroqRateLimitError`.
   - Unwraps `openai.APIConnectionError` causes back into typed `GroqModelError` instances.
3. **Comprehensive Test Suite** (`services/agent/tests/test_groq_model.py`):
   - 18 focused tests exercising construction validation, target refusal, deadline expiration, sticky send budget across stages, Strands tool execution, retry/continuation budget exhaustion, stage 2 extraction wire shape and response parsing (valid, null fields, refusal, invalid JSON), 429 preservation, and cancellation/resource cleanup.
4. **Sanitized Wire Evidence** (`services/agent/test-evidence/bs012/`):
   - `stage1_tool_wire.json`: Stage 1 turn 1 outgoing JSON with `tools` array, `stream: true`, `stream_options`, and NO `response_format`.
   - `stage2_extraction_wire.json`: Stage 2 outgoing JSON with strict `response_format` for `_Extraction` (`strict: true`, `additionalProperties: false`, all 4 nullable fields required), `stream: false`, NO `tools`, NO `tool_choice`, NO `stream_options`.
   - `test_results.txt`: Complete command output and verification record.
