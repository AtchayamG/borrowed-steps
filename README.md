# Borrowed Steps
Borrowed Steps keeps community mobility equipment moving to the next person who needs it.
Track: Good Neighbor Agents, Agents for Humans Hackathon.
Status: architecture and task contracts only; no working application, deployment or Strands execution yet.
Planned workflow: request, equipment readiness, human allocation, pickup, return and inspection.
Synthetic evaluation data; no medical advice or suitability decisions.
See docs/PRODUCT_SPEC.md, TECH_SPEC.md, ARCHITECTURE.md, API_CONTRACT.md and MILESTONES.md.
Final requirements: real Strands, persistent public workflows, human decisions, public MIT repo, architecture diagram, public English video <=5 minutes and independently passed live-release report.
